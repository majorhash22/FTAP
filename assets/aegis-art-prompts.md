# Aegis surface artwork

Created with the built-in image_gen tool using the user's supplied front / edge / back reference. Both assets retain the generated PNG bytes and true transparency. The geometry outline is derived from the front image's alpha channel; images are not stretched into a generic shield shape.

- Front: aegis-front-detailed.png
- Back: aegis-back-detailed.png
- Geometry metadata: aegis-shape.js
- Direct-file texture copies: aegis-local-textures.js
- Rebuild metadata after changing images: node tools/build-aegis-art.cjs

## Front prompt

Use case: game-asset. Asset: high-resolution front-facing color texture / cutout for an interactive 3D Aegis trophy on a dark website. Reference image 1 is the user's exact desired trophy, showing FRONT at left, EDGE at middle, BACK at right. Create ONLY the FRONT trophy from the left-hand view. Faithfully preserve its Aegis silhouette, proportions and ornamental design: broad circular upper shield, pronounced concave side notches below the circle, narrow lower neck and flared base; thin hard bronze rim with dark pierced filigree, top crest, two large opposing C-shaped / S-like silver relief panels intricately carved with tiny mythological warriors and dragons, dark oxidized metal field, intricate central bronze spiral medallion, four bronze circular studs. This must look like real aged cast bronze and engraved silver with fine sharp chiseled detail, dark crevices, polished worn edges, NOT soft dough, NOT bread, NOT rubber, NOT a simplified cartoon, NOT a smooth rounded plaque. Straight-on ORTHOGRAPHIC front elevation, centered, no tilt, no visible side thickness, no perspective distortion. Neutral studio material lighting, gentle even illumination so it works as an albedo surface on a 3D mesh; no strong directional cast shadow, no glow. Fill the frame closely with only a small uniform transparent margin, complete intact edges. Square 2048 x 2048 output. Background fully transparent with true alpha; no floor, no environment, no writing, no labels, no extra shields, no watermark. Use the supplied reference for exact visual identity and details.

## Back prompt

Use case: game-asset. Asset: high-resolution BACK-face surface texture for an interactive 3D Aegis trophy. Two reference images are provided: the user's three-view Aegis reference (front, thin edge, and back) is the design reference; the newly generated single-front trophy cutout is the exact silhouette/proportion and material reference. Create ONLY a straight-on ORTHOGRAPHIC BACK view of the same shield. Match the silhouette of the single-front reference exactly: broad rounded upper shield, deep concave side notches, narrow lower neck, flared lower feet and curved base. Back design must faithfully follow the right-hand back view in the user's reference: aged thin bronze outer rim with sharp pierced filigree, a dark diagonal woven-texture inset, a large polished circular SILVER PLATE with a wide SILVER outer engraving annulus and fine inner ring, small silver rivets, and the large centered opposing-curves / S-like emblem incised into the central plate. The silver annulus needs to be clean BLANK metal so player names can be added in code. No text, names, dates, logos with text, or labels anywhere. Extremely fine real metal detail, worn bevels, crisp tool marks and dark cut-out grooves. Actual cold silver/steel and restrained patinated bronze, not doughy or overly orange; not soft, rounded, bread, rubber, plastic or cartoon. Neutral, even studio material lighting with minimal baked shadows; no dramatic external lighting. Zero perspective tilt; no visible side edge; no shadows behind the object. Single centered BACK shield only, tightly framed with a small transparent margin, intact edges. Square 2048 by 2048 output. TRUE TRANSPARENT background, no scene, no floor, no watermark.
